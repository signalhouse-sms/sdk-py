> **This package has moved.** `signalhouse` is now [`signalhouse-sms`](https://pypi.org/project/signalhouse-sms/), developed at
> https://github.com/signalhouse-sms/sdk-py. This package is a thin shim that installs `signalhouse-sms` at the
> same version and re-exports it. It receives every release until **2027-05-01**, then stops.
>
> **Migrate:** `pip install signalhouse-sms`, then change `import signalhouse` / `from signalhouse…` to `signalhouse_sms`. The API is identical.
